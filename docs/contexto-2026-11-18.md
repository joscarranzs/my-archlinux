## 4. Traps

- `FileView.fileChanged()` does not refresh `text`: call `reload()`, read in
  `onLoaded`. Reading it on the signal fed stale payloads to both sides.
- `os.replace` hands a file a new inode and kills the peer's watch; a watched
  channel needs in-place writes plus a `generated: 0` sentinel for partial reads.
- `notification.tracked = false` re-emits `closed`: a close handler needs a per-key
  re-entrancy flag or it overflows the stack and the daemon stops recording.
- `grim` costs ~500 ms per capture; time a 240 ms animation from QML logs, not pixels.
- A `MouseArea` anchored inside a `Row` warns and mislays out; use `TapHandler`.
- Skills the curator created are not this session's commits: the 19 dirty paths
  went in their own `docs(skills)` commit on the user's ruling, never folded into
  a code commit.
- The agent's write tools refuse `~/.hermes/config.yaml` (config guard); config
  edits go through a sanctioned writer or the user's own hand. The user removed
