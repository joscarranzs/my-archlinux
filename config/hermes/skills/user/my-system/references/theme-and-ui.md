# Theme and UI

## Generation pipeline

Sources, hand-owned: `~/.dotfiles/theme/{colors,look,animations,typography}.json` and `scripts/theme/templates/{general,tools}/*.tpl`.

`scripts/theme/apply-theme.py` renders them into `~/.config/hypr/{theme,look,animations}.lua`, GTK settings and CSS, `~/.config/sddm/arch/*.qml`, kitty config, fontconfig, Quickshell `Appearance.qml` and `MaterialIcon.qml`, starship, yazi and the Hermes skin. It writes atomically (temp file + `os.replace`): Quickshell reloads a config the instant its path changes, so a plain write once exposed an empty QML file and killed the bar. Generated files carry `GENERATED_MARKER = "Generated by scripts/theme/apply-theme.py"`; never hand-edit one. The generator's gates abort without writes on role, type-scale or motion drift.

Palette `warm-paper`: base `#efecef`, ink `#2a2222`, accent `#007952`, gilt `#997900`, danger `#d01b31`. Contrast report: 91 pairs, 0 under target. Re-run it after theme changes.

## Visual invariants

- Motion has one source: `theme/animations.json` -> generated `Appearance.qml` (`motionControlDuration` 110, press 80, entrance 200). No QML reads the JSON at runtime; `reducedMotion` emits zero durations.
- Icons use one generated ladder: 14/18/22/28/40/48 (`iconXs..iconTile`). App tiles take `iconTile`, not `iconXs`; launcher cell is 112 px.
- Hover and press are material roles, not an extra wash: fill steps one rung up with a gilt edge, press steps down at 80 ms. Reuse the existing recipe, e.g. BarClock's 32 px button for a copy target.
- An overlay scrim binds the plaque's entrance: `opacity: panel.opacity`. Never animate it beside the plaque.
- A light surface swallows white artwork. `~/.dotfiles/scripts/icon-contrast.py` needs `--background light` for that direction.

## QML traps already paid for

- An undefined colour or shape role fails silently: a white mark tile, a square pip. Diff `appearance.*` reads against the roles the surface's `Appearance.qml` declares.
- `Quickshell.iconPath()` answers for every string, so a truthiness guard is dead code. Use `~/.scripts/session/notify-icon.py`; it prints nothing when no icon resolves. Hold `PanelCard.markPending` while an async answer is in flight, and remember the plate and glyph gates are separate rules.
- Hover driven by `hyprctl dispatch movecursor` does not move the cursor; use component `forceHover` hooks and offscreen grabs. For a toplevel in Lua, `hl.dsp.cursor.move({x=…,y=…})` works, but warp away and back to generate motion. Layer surfaces ignore it.
- Offscreen harnesses must live inside `~/.config/quickshell/`; imports use `file:/abs/path` with one slash. State harnesses render components, not `shell.qml`, so a duplicate binding in a shell can survive green tests: open the shell once and read the log.
- One Quickshell process per panel. Restart only its instance, then run its launcher. Use a bracketed pattern such as `pgrep -f 'quickshell -n -p .*bar/shell[.]qml'`; unbracketed `pkill -f` also kills the shell running it.

- SDDM 0.21.0-7 uses theme `arch`, sourced from `~/.dotfiles/config/sddm/arch/` and generated from templates. The greeter shows at next login.
